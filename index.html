Klik Tambah barang. Isi nama, kategori, dan jumlah. Kode dibuat otomatis; lokasi dan catatan boleh menyusul.

Buka Cadangan data → Unduh cadangan setelah selesai mendata. Untuk pindah perangkat, buka website di perangkat tujuan lalu pulihkan file JSON tersebut.

Yang perlu diketahui

Apakah data langsung terlihat oleh seluruh tim?

Belum. Versi ini menyimpan data di browser masing-masing, tanpa database bersama dan tanpa login. Gunakan satu browser utama untuk pencatatan. Berbagi file cadangan adalah pemindahan data manual, bukan sinkronisasi.

Bagaimana mencatat barang dengan kondisi berbeda?

Buat baris terpisah, misalnya “Arduino Uno — baik” dan “Arduino Uno — rusak”. Jumlah dalam satu baris harus memiliki satu kondisi, satu satuan, dan satu lokasi yang sama.

Apakah satu kode berarti satu unit fisik?

Tidak. Satu kode mewakili satu baris inventaris. Contoh: IROS-ELK-001 bisa berisi 10 unit Arduino. Untuk robot yang perlu dilacak sendiri, buat satu baris per robot. Komponen di dalam kit tidak otomatis dihitung lagi sebagai stok lepas.

Apa bedanya CSV dan cadangan JSON?

CSV adalah daftar barang sesuai pencarian dan filter saat ini, untuk dibuka di aplikasi spreadsheet. JSON adalah cadangan seluruh data yang dapat dipulihkan kembali. Website ini tidak mengimpor Excel atau CSV.

Bagaimana dengan peminjaman dan kondisi stok?

Versi sederhana ini belum memiliki modul peminjaman, perincian isi kit, atau pengelolaan pengguna. Jumlah menunjukkan stok yang Anda catat, bukan perhitungan otomatis jumlah tersedia setelah peminjaman.

Hindari mode incognito untuk data asli. Jangan menghapus data situs sebelum mengunduh cadangan. Data saat membuka file langsung berbeda dari data di alamat GitHub Pages.
